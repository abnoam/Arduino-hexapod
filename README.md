# 🤖 Arduino Hexapod Robot

## Overview
פרוייקט כיתה יב של נועם ויוסי - רובוט הקספוד (עכביש ששש רגליים) המונע על ידי Arduino Mega

**Arduino Hexapod** הוא רובוט אוטונומי בעל שש רגליים המופעל ע"י Arduino Mega עם בקרה דרך תקשורת סדרתית (Serial). הרובוט מסוגל לבצע תנועות מורכבות, ריקודים וחיקוי התנהגויות של חרקים אמיתיים.

---

## 🎯 יכולות הרובוט

### תנועה בסיסית
- **🚶 הליכה קדימה** (`walk.forward.ino`) - תנועה רגילה קדימה עם חיישן PIR קדמי
- **🔙 הליכה לאחור** (`walk.backward.ino`) - תנועה אחורה עם חיישן PIR אחורי
- **➡️ פנייה ימינה** (`right.ino`) - סיבוב מבוקר לימין
- **⬅️ פנייה שמאלה** (`left.ino`) - סיבוב מבוקר לשמאל
- **⏹️ עצירה** (`still.ino`) - הרובוט נשאר במצב כיסא/עמידה

### מצבי גוף
- **🪑 ישיבה** (`sit.ino`) - הרובוט יושב עם רגליו קרובות לגוף
- **🧍 עמידה** (`stand.ino`) - הרובוט עומד בגובהו המלא

### פעולות מיוחדות
- **💃 ריקוד 1** (`dance1.ino`) - רצף תנועה ראשון עם מוזיקה
- **🕺 ריקוד 2** (`dance2.ino`) - רצף תנועה שני עם מוזיקה
- **👋 ניפנוף** - תנועת כף יד (במצב ריקוד 9)
- **⚡ רקיעת רגל** (`boogi()`) - תנועה דינמית של רגליים

### חיישנים וגילוי
- **🔴 חיישנים PIR** - 2 חיישנים לגילוי תנועה (קדמי ואחורי)
- **🎵 מודול MP3** - הפעלת קבצי אודיו עבור הריקודים
- **📡 בקרה RF** - קבלת פקודות דרך תקשורת סדרתית

## 🏗️ חומרה (Hardware)

### Arduino Mega 2560
- מעבד ראשי של המערכת
- 18 יציאות Servo PWM (לשליטה על 18 סרוו)

### סרוו מוטורים
- **18 סרוו** בכל רגל (3 סרוו לכל רגל):
  - **Servo 1**: שליטה בכתף (כיוון לפנים/החוצה)
  - **Servo 2**: שליטה במרפק (כיווני U-כיוון)
  - **Servo 3**: שליטה בשוק (כיווני U-כיוון)
- **6 רגליים**: 3 ימנית (Right Leg) + 3 שמאלית (Left Leg)

### חיישנים
- **2x חיישני PIR** (Passive Infrared) - גילוי תנועה אנושית

### אודיו
- **מודול MP3** - הפעלת מוזיקה ותופעות קול

### תקשורת
- **UART Serial3** (pins 17-16) - תקשורת עם מודול RF/בקרה

## 🎮 פקודות בקרה

הרובוט מקבל פקודות דרך `Serial3` בפורמט של תו בודד:

| פקודה | פעולה | פרטים |
|------|------|--------|
| `1` | ישיבה | הרובוט יושב למצב נמוך |
| `2` | עמידה | הרובוט עומד ברגליים מיושרות |
| `3` | הליכה קדימה | תנועה קדימה עם חיישן PIR קדמי |
| `4` | הליכה לאחור | תנועה לאחור עם חיישן PIR אחורי |
| `5` | פנייה ימינה | סיבוב לימין |
| `6` | פנייה שמאלה | סיבוב לשמאל |
| `7` | עצירה | עצירת תנועה וביטול מוזיקה |
| `8` | ריקוד 1 | ריקוד ראשון עם מוזיקה |
| `9` | ריקוד 2 | ריקוד שני עם ניפנוף |
| `a` | חיישן PIR | הרובוט יושב עד שיגיל תנועה, ואז קם |

## 🔧 כיול ובהגדרה

כל סרוו מקבל ערך התחלתי (angle) בטווח 0-180 מעלות:
- **מצב ברירת מחדל**: כל סרוו מוגדר לזווית בסיסית (בדרך כלל ~90 מעלות)
- **כיול אישי**: כל רגל מכיילת בנפרד למצב הטוב ביותר
- **עומק תנועה**: כל תנועה מתאימה את זוויות הסרוו בתוך טווח מסוים

## 📚 דוגמאות שימוש

### השגת הליכה קדימה
```cpp
forward();  // הרובוט הולך קדימה
```

### השגת ריקוד
```cpp
mp3.play(2);    // הפעלת קובץ מוזיקה
dance1();       // ביצוע ריקוד
```

### גילוי תנועה ותגובה
```cpp
bool motion = pir();  // בדיקת חיישן PIR
if(motion) {
  stand();  // קום אם קיימת תנועה
}
```

פרוייקט זה משלב מספר מושגים חשובים:

1. **בקרה מעגלית** - שימוש ב-Servo ולבקרת PWM
2. **אינטראקציה סדרתית** - תקשורת עם מודולי חומרה חיצוניים

4. **חיישנים** - שימוש ב-PIR לגילוי אוטונומי
5. **עיבוד אודיו** - שליטה במודול MP3
