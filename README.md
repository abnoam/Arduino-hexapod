## 🏗️ חומרה (Hardware)

### Arduino Mega 2560
- מעבד ראשי של המערכת
- 18 יציאות Servo PWM (לשליטה על 18 סרוו)

### סרוו מוטורים
- **18 סרוו** בכל רגל (3 סרוו לכל רגל):
  - **Servo 1**: שליטה בכתף (כיוון לפנים/החוצה)
  - **Servo 2**: שליטה במרפק (כיווני U-כיוון)
  - **Servo 3**: שליטה בשוק (כיווני U-כיוון)
- **6 רגליים**: 3 ימנית + 3 שמאלית

### חיישנים
- **PIR** (Passive Infrared) - גילוי תנועה אנושית

### אודיו
- **מודול MP3** - הפעלת מוזיקה

### תקשורת
- **UART Serial3** (pins 17-16) - תקשורת עם מודול RF/בקרה

## 🎮 פקודות בקרה

הרובוט מקבל פקודות דרך `Serial3` בפורמט של תו בודד:

| פקודה | פעולה | פרטים |
|------|------|--------|
| `1` | ישיבה | הרובוט יושב למצב נמוך |
| `2` | עמידה | הרובוט עומד ברגליים מיושרות |
| `3` | הליכה קדימה | תנועה קדימה עם חיישן PIR קדמי |
| `4` | הליכה לאחור | תנועה לאחור עם חיישן PIR אחורי |
| `5` | פנייה ימינה | סיבוב לימין |
| `6` | פנייה שמאלה | סיבוב לשמאל |
| `7` | עצירה | עצירת תנועה וביטול מוזיקה |
| `8` | ריקוד 1 | ריקוד ראשון עם מוזיקה |
| `9` | ריקוד 2 | ריקוד שני עם ניפנוף |
| `a` | הרובוט עוצר עד שאין בדרכו משהו |
